# CivicPlus

> CivicPlus is a govtech company providing an integrated platform for local, state, and education government operations — municipal websites, agenda and meeting management, recreation management, community development (permitting, licensing, code enforcement), utility billing, mass notification, public records (NextRequest), and the SeeClickFix 311 resident-request CRM. Its most developer-facing public API is the SeeClickFix API v2, which also exposes an Open311 GeoReport v2 compatible endpoint.

## APIs

- [SeeClickFix API v2](https://dev.seeclickfix.com/): REST API over issues, comments, users, places, questions, and answers. Base URL https://seeclickfix.com/api/v2.
- [SeeClickFix Open311 endpoint](https://seeclickfix.com/open311): Open311 GeoReport v2 compatible interface (services, requests, tokens).
